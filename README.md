# MAM - Missing App Monitor · Tải về

Phần mềm quản lý, giám sát và điều khiển máy tính trong mạng LAN.

**Phiên bản mới nhất: 1.1.56** — bấm vào tên file bên dưới, rồi bấm nút tải (Download raw file).

| File | Dùng cho |
|---|---|
| [`MAM-Server-Setup.exe`](MAM-Server-Setup.exe) | Cài server trên máy chủ Windows (một file, có giao diện) |
| [`MAM-Agent-Setup.exe`](MAM-Agent-Setup.exe) | Cài agent trên máy nhân viên Windows |
| [`MAM-1.1.56.zip`](MAM-1.1.56.zip) | Bộ đầy đủ: server, agent, Console cho Windows / Linux / macOS, Windows 7/8, Android, hướng dẫn PDF và mã nguồn |
| [`MAM-Huong-dan-vi.pdf`](MAM-Huong-dan-vi.pdf), [`MAM-Guide-en.pdf`](MAM-Guide-en.pdf), [`MAM-Guide-zh.pdf`](MAM-Guide-zh.pdf) | Hướng dẫn cài đặt và sử dụng |
| [`MAM-Gioi-thieu-vi.pdf`](MAM-Gioi-thieu-vi.pdf), [`MAM-Intro-en.pdf`](MAM-Intro-en.pdf), [`MAM-Intro-zh.pdf`](MAM-Intro-zh.pdf) | Giới thiệu ngắn |

Kiểm tra file zip: so mã SHA-256 trong `MAM-1.1.56.zip.sha256`.

## Cài nhanh
1. Trên máy chủ: chạy `MAM-Server-Setup.exe` (quyền Administrator), mở `http://<IP-máy-chủ>:7070`, tạo tài khoản Super admin.
2. Trong Console vào **Cài đặt**, tải agent đã gắn sẵn địa chỉ server, chạy trên từng máy nhân viên.
3. Chi tiết xem file hướng dẫn PDF.

Mã nguồn: https://github.com/taitan0118/MAM
